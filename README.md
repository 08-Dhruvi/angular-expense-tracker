# Angular Expense Tracker

A feature-rich Expense Tracker application built with Angular.

## Features

* Add Expense
* Edit Expense
* Delete Expense
* Search Expenses
* Category Filter
* Sort by Amount
* Sort by Date
* Dashboard Cards
* Monthly Summary
* Pie Chart Visualization
* Export to Excel
* Local Storage Persistence

## Technologies Used

* Angular 21
* TypeScript
* Reactive Forms
* Chart.js
* XLSX
* HTML
* CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/08-Dhruvi/angular-expense-tracker.git
```

Navigate to the project folder:

```bash
cd angular-expense-tracker
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
ng serve
```

Open:

```text
http://localhost:4200
```

## Project Highlights

* Built using Angular standalone components
* Form validation using Reactive Forms
* Data persistence using Local Storage
* Interactive Pie Chart dashboard
* Excel export functionality
* Search, filtering, and sorting capabilities
